# GuateFlow: Extension de VS Code para Guatecompras
# =================================================================

GuateFlow es una extension de Visual Studio Code enfocada en el contexto
guatemalteco: consulta de licitaciones publicas (OCDS de Guatecompras),
validadores de identificacion y utilidades de formato y calculo laboral.

## 1. Capacidades previstas

1.1 Funciones libres: validador de DPI/NIT, calculadora laboral (Bono 14,
Aguinaldo, Indemnizacion, Preaviso y Vacaciones), formateador de fechas y
montos, y barra de estado con licitaciones vigentes.

1.2 Funciones Pro: cliente de la API OCDS, panel de arbol de licitaciones,
webview de detalle, filtros por entidad, monto y palabra clave, y licenciamiento
via clave de producto.

## 2. Estado del proyecto

2.1 El repositorio contiene el scaffolding de la extension (`vscode-ext/`),
la aplicacion web de apoyo (`webapp/`) y documentacion de producto.

2.2 El roadmap por fases, nombres de publicacion y plan de marketing estan
documentados en `docs/guateflow-guide.md`.

## 3. Documentacion

3.1 `docs/guateflow-guide.md`: guia de nombres, roadmap y marketing.

3.2 `docs/tender-proposal.md`: plantilla de propuesta tecnica para
licitaciones de infraestructura cloud.

## 4. Licenciamiento

4.2 Las funciones Pro se distribuyen bajo licencia propietaria con clave
de activacion.
